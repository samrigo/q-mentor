# Pasqal/Pulser — capability report first

Pulser programs neutral-atom registers with pulses. It is **not** a generic QUBO
compiler: couplings are `C6 / r^6` (always positive), set by geometry, and a
global channel applies one detuning to every atom.

- **SDK:** `pulser==1.9.1` (`pulser-core`, `pulser-simulation`)
- **Device:** `pulser.devices.AnalogDevice` (C6 = 865723.02 rad·µm⁶/µs, min distance 5 µm, radius ≤ 38 µm, `rydberg_global` only)
- **Emulator:** `pulser_simulation.QutipBackendV2` (the older `QutipEmulator` is deprecated as of 1.9)

## 1. Six-bond QUBO → `unsupported-exact`

`capability_report.json` (regenerated by `main.py`):

| Check | Result |
|---|---|
| Coupling sign (all `b_ij > 0`) | pass |
| 15 independent couplings vs 9 geometric degrees of freedom in 2D | **fail** |
| Best-fit embedding (log-ratio fit, 20 restarts) | **fail** — max relative coupling error ≈ 375 % |
| Device distance limits for the best fit | pass |
| Six distinct linear terms need local detuning/DMM | **fail** — AnalogDevice is global-only |

No six-bond sequence is generated, and no approximation is offered (error far
above the 10 % bound). Alternatives: gate-model or D-Wave targets (sibling
folders), a geometry-native reformulation, or a DMM-capable device with a
labelled error bound.

## 2. Supported example: geometry-native 4-atom QUBO

Four atoms on a line, 6 µm apart. The QUBO is defined by the register:
`E(x) = Σ U_ij x_i x_j − δ Σ x_i`, `δ = 6 rad/µs`. The test recomputes the
Rydberg Hamiltonian diagonal from device data for all 16 states.

QAA sequence: 4 µs, Ω ramps 0 → 2π·0.8 → 0 rad/µs, δ sweeps −6 → 6 rad/µs.

## Run

```bash
uv venv && uv pip sync requirements.lock
python main.py
python -m pytest -q
```

## Observed result (2026-10-13)

Exact optimum `1001` (energy −11.9745 rad/µs); runners-up `1010`/`0101` at
−11.7101. Noiseless emulation: P(optimum) = 0.46, with > 95 % of the mass on the
three independent sets. SPAM noise (prep 0.5 %, false-pos 1 %, false-neg 5 %, 20
trajectories): P(optimum) = 0.39. Evidence level 2 on a toy.
