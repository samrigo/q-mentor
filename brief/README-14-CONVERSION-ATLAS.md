# Cross-Hardware Conversion Atlas

This is the build contract for `q-mentor-convert`, not a promise that every physical machine can execute every program. Resolve **source program → source semantics → canonical problem or operator → target capability → target implementation**. Never treat a shared language, QASM file, or vendor cloud as proof of hardware equivalence. See [README-10](README-10-CODE-CONVERSION.md) for the complete-file and optimization gates.

## Classify every requested route

`E` = exact logical computation on a supported operation subset; `C` = equivalent **conditional** distribution after heralding/postselection; `R` = same classical problem or objective reimplemented with a different quantum algorithm; `A` = quantified approximation to evolution; `U` = unsupported or no verified programming route. These are *candidate* classifications. Upgrade a requested edge only after its version-pinned fixtures pass; `E` never means equal noise, success probability, wall time, or cost.

| Source model ↓ / target → | Gate circuits | Rydberg analog | BQM/anneal | Photonic DV | Photonic CV | Research-only hardware |
|---|---|---|---|---|---|---|
| Gate circuits | `E` on supported subset | `A` or `R` | `R` only if objective recovered | `C` on supported dual-rail subset | `U` by default | `U` |
| Rydberg analog | `A` or `R` | `E` only if Hamiltonian/control match | `R` only if objective recovered | `U` | `U` | `U` |
| BQM/anneal | `R` | `R` if geometry permits | `E` energy model; dynamics differ | `R` only with an explicit encoding | `U` | `U` |
| Photonic DV | `C` only with verified inverse encoding | `U` | `R` only if objective recovered | `E` on supported optical model | `U` by default | `U` |
| Photonic CV | `U` by default | `U` | `U` | `U` by default | `E` only on matched CV model | `U` |
| Research-only hardware | `U` for executable code | `U` | `U` | `U` | `U` | `U` |

Superconducting gates, trapped-ion gates, accessible silicon/diamond/spin gates, cat-qubit logical gates, and tiny NMR gate devices enter the **gate** row only after their actual native operations and SDK path are verified. Pasqal/QuEra analog devices enter **Rydberg analog**; D-Wave enters **BQM/anneal**; Quandela enters **photonic DV**. Xanadu-style CV remains separate. Electron-on-helium and topological prototypes stay **research-only** until a public, versioned, executable contract exists. This grouping covers all physical families in [README-11](README-11-HARDWARE-AND-RESEARCH.md) without inventing 121 pairwise adapters.

## Version-matched conversion recipes

| Route | Build from current official source | Preserve and test; refuse when absent |
|---|---|---|
| Gate ↔ gate across IBM/Google/Rigetti/IQM/OQC/ions, and gate-capable layers | Prefer maintained [pytket–Qiskit conversion](https://docs.quantinuum.com/tket/extensions/pytket-qiskit/api.html), [pytket–Braket conversion](https://docs.quantinuum.com/tket/extensions/pytket-braket/api.html), or a tested [Cirq QASM subset](https://quantumai.google/cirq/build/interop). [PennyLane imports Qiskit](https://docs.pennylane.ai/en/stable/introduction/importing_workflows.html) through its separately pinned plugin. Classiq and Q# are high-level languages: compile/rebuild from intent when no verified importer exists. | Operator up to global phase, bit/wire order, measurements/keys, classical control, reset, custom gates, parameter binding, native basis, connectivity, and results. QASM import is subset support, not general translation. [pytket warns](https://docs.quantinuum.com/tket/extensions/pytket-qiskit/api.html) about symbolic conversion and implicit swaps. |
| Gate → photonic DV, and reverse | Use version-pinned [Perceval Interop](https://github.com/Quandela/Perceval_Interop) and its [Qiskit bridge documentation](https://perceval.quandela.net/interopdocs/) for supported dual-rail circuits; resolve the docs version against the pinned package. The reverse route needs an explicit optical-to-logical decoder; no generic inverse is assumed. | Modes per qubit, photon/ancilla count, heralding, postselection, detector/loss model, conditional output distribution **and unconditional success rate**. Never present postselected fidelity as deterministic equivalence. |
| Gate → physical cat or NMR device | Treat [Alice & Bob's Qiskit provider](https://github.com/Alice-Bob-SW/qiskit-alice-bob-provider) and [SpinQit](https://github.com/SpinQTech/SpinQit) as distinct target compilers; start with local emulators and a tiny supported gate fixture. Emit an executable adapter only after its `tested-local` promotion; otherwise report capability. The reverse route exports a *logical* circuit only when measurements and controls are recoverable. | Physical versus logical backend, noise bias, native gates, qubit and coherence limit, temperature, measurement semantics. A simulator or logical cat emulator is not evidence of QPU execution. |
| Pulser ↔ Bloqade ↔ Braket AHS; Qadence → Pulser | Translate the *time-dependent Hamiltonian*, not Python calls. Compare [Pulser waveforms](https://docs.pasqal.com/pulser/pulses/), [Bloqade analog](https://www.bloqade.quera.com/vendored/bloqade-analog/), and [Braket AHS/Aquila](https://docs.aws.amazon.com/braket/latest/developerguide/braket-quera-submitting-analog-program-aquila.html). The [Qadence–Pulser bridge](https://pasqal-io.github.io/qadence/latest/api/backends/pulser/) is experimental and Qadence is not actively maintained; treat it as a pinned legacy source, never the default target. | Atom coordinates, `C6/r^6` interaction, units and signs, drive amplitude, detuning, phase, local/global addressability, time grid, device limits, initial state, and readout. If waveform/control sets differ, report bounded `A` or `U`; a shared Ising label is insufficient. |
| Analog ↔ gate | Only a documented digital-analog decomposition or Hamiltonian simulation can yield `A`; report Trotter/synthesis error and resources. Re-expressing a shared QUBO as QAOA is `R`, as in the [Pasqal → Classiq case](README-10-CODE-CONVERSION.md). | Compare evolution or the canonical objective as appropriate; never call a circuit equivalent to an analog pulse schedule because it reaches the same minimum. Preserve interaction, schedule, geometry, measurement and noise assumptions. |
| BQM/anneal ↔ gate/analog/photonic | Use [D-Wave's BQM offset and Ising/QUBO transforms](https://docs.dwavequantum.com/en/latest/ocean/api_ref_dimod/models.html) and [Qiskit optimization converters](https://qiskit-community.github.io/qiskit-optimization/tutorials/02_converters_for_quadratic_programs.html). The reverse route extracts a declared objective; a general circuit or sample distribution has no BQM inverse. | Every bitstring's canonical energy, constant, penalty, feasible set, bit order, and decode. Annealing schedule, gate-model QAOA, analog evolution, and photonic sampling are different algorithms even when they optimize the same function. Geometry/embedding and postselection may rule out the target. |
| CV photonics ↔ DV/gate; research-only families | Teach and assess only until an official, maintained converter and actual backend contract are verified. Do not route through the archived Strawberry Fields repository as a maintained SDK. | Encoding, continuous observables, squeezing/non-Gaussian resources, cutoffs, loss, and sampling interpretation. Electron-on-helium, topological, or unavailable spin devices receive a capability report, **not** generated executable code. |

## Fresh-SDK and proof gate

At build time and before each release, read the exact target SDK's official docs, release/changelog, repository tag/commit, relevant open and closed issues, Python/runtime compatibility, and one maintained example from [README-12](README-12-SDK-SOURCE-MAP.md). Record `checked_at`, installed package version, full commit SHA, example path/license, and unresolved limitations in `ConversionEdge`. Pin a **compatible tested set**, never copy `main` as though it were a version. Official blogs may suggest a recipe; documentation and tested source determine API calls.

As checked 2026-10-14, [Quantinuum marks `pytket-cirq`, `pytket-pennylane`, and `pytket-pyquil` unmaintained](https://docs.quantinuum.com/tket/api-docs/extensions.html). Do not use them as default bridges. Its current [pytket–Qiskit changelog](https://docs.quantinuum.com/tket/extensions/pytket-qiskit/changelog.html) and [Quantinuum backend guide](https://docs.quantinuum.com/tket/extensions/pytket-quantinuum/) must be reread: remote submission moved to `qnexus` at version 0.56.0. Version drift is a test failure, not a prompt-repair opportunity.

For every edge claimed `E`, `C`, `R`, or `A`, generate complete pinned files and a negative fixture. Test syntax/import, source and target local execution, all toy basis-state energies when an objective exists, statevector/operator equivalence on small unitary cases, shot distribution and decoder on measured cases, and resources/cost. `C` also tests unconditional success; `A` states an error tolerance; `R` labels the algorithm change. Test one representative route in each matrix class plus every adapter actually shipped. Unsupported routes return a concise reason and nearest valid alternative, never a speculative bridge.
