# q-mentor-exec

## Preconditions

- ResultRecord(s) and BenchmarkRecord(s) must exist.
- Do not invent numbers or claims from a design alone.

## Output structure (≤1 page)

1. Decision recommendation (classical_now / research_poc / bounded_experiment)
2. Evidence summary (1–3 bullets)
3. Classical alternative and gap
4. Cost / risk / next gate
5. Sources / result-record IDs

Follow `templates/executive-brief.md`.
